Proclaim Version 4.11

New

  • Support 4K canvas and media uploads. Upload your 4K media files, then choose the 4K aspect ratio on your virtual screen in the Display settings.
  • Add optional media player as an alternative to Windows Media Player. Enable it in General settings.

Improved

  • Scroll item into view on timeline or grid preview with a click to prevent accidental slide changes. Double-click in the Order of service to jump to a service item.
  • Enhance sync icon to display breakdown of any sync service issues.
  • Support Apple HEIC/HEIF format (Mac only).
  • Update to new web-based authorization portal.

Fixed

  • Investigate and fix issue with free trial still showing lock.
  • Show correct first frame when transitioning to video item with an altered start time.
  • Prevent grid preview from jumping to the top of the presentation when a change is synced.
  • Make sure the Order of Service "Rename" context menu option operates on the selected item.
  • Ensure "Fix to textbox" option cannot be disabled for countdown background shapes.
  • Truncate long foreground element names in the Smart Media Creator.
  • Prevent crash when compressing files (Mac only).
  • CHECK Prevent rare timing-related crash loading the presentation Edit view (Windows only).
  • Always show the "switch songs" button in the Song Library.
  • Prevent resizing of the Notes field in the Song Library arrangement view.
  • Consistently close Song Library window with a single click (Windows only).
  • Some image files stretch across the canvas when imported as foreground images.
  • Prevent images from losing orientation metadata.
  • Make sure PayPal Cancel button returns Proclaim to the checkout screen.
