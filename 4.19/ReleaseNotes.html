Proclaim Version 4.19

Tuesday, June 9, 2026 - Proclaim 4.19.0.0166

  • Fixed a crash that could occur after a successful checkout.

Thursday, June 4, 2026 - Proclaim 4.19.0.0156

  • Restore block paragraph Bible text layout functionality, adding back blank lines for paragraph breaks.
  • Add a new Bible text layout option for single paragraph.
  • Prevent VERSE_BOUNDARY text from appearing on Bible slides in KJV as the Bible version when using one verse per slide.

Tuesday, June 2, 2026 - Proclaim 4.19.0.0148

New

  • Allow web sign-in via Edit view in order to to authorize SongSelect video setlists.

Fixed

  • Remove extra blank lines from Bible slides.
  • Include CCLI numbers when importing songs from the CCLI song library.
  • Prevent rare hang when going On Air with NDI and live video enabled (Mac only).
  • Fix typo in the group creation dialog.
  • Prevent a hang when adding multiple long passages to a Bible item.
  • Fix soft returns appearing as boxes on the Confidence Monitor.
  • Prevent a sync from refreshing the entire presentation unexpectedly.
  • Correct upload status so machines correctly reflect when content is not yet uploaded.
  • Prevent a crash when opening a presentation with a different aspect ratio.
  • Keep "Set as default Song" settings from being lost for song media slides.
  • Fix Confidence Monitor slide generation for song lyrics with wrapped list items.
  • Fix Planning Center song imports when the CCLI ID is missing or arrangements are empty.
  • Prevent a crash when toggling the Media Browser sidebar.
  • Prevent a crash at startup with a slow or intermittent connection (Mac only).
  • Prevent a crash when dragging items from the Media Browser web view.
  • Fix slide generation issues caused by lone brackets in text.
  • Fix song slide transitions not updating when changed from the default to "no transition".
  • Fix random spaces appearing in the middle of words in song lyrics.
