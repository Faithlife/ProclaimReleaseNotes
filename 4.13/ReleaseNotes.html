Proclaim Version 4.13

Thursday, August 28 2025 - Proclaim 4.13.0.0008

  • Fix crash changing teams with an image slideshow as the active item.

Monday, August 25 2025 - Proclaim 4.13.0.0006

New

  • Introduce Service Builder. Use Service Builder to quickly add Song and Bible items to your presentation. Access Service Builder via the Add Item menu, or click the button next to the presentation title.

Improved

  • Allow Default Media and Confidence templates to be created from Settings.
  • Add options for multi-line preview to Confidence templates.
  • Make 'Use video player when available' option selected by default
  • Provide auto-play options for background audio.
  • Allow recording cues to be hidden.

Fixed

  • Scale Floating hearts and Amens correctly in 4K virtual screens.
  • Scale countdown clock correctly in 4K confidence monitor.
  • Ensure Web items stop playing audio and video content when slide is advanced.
  • Update and display Last shown quickscreen correctly after slide edits.
  • Fix crash editing a default template on a new virtual screen.
